# Rules for agents working on Aya

- When debugging or driving Aya teams, never make a team agent read files outside the project directory it works in; paste the content into the message instead (a first read outside made Claude Code offer an account-wide read block that froze every session, 2026-10-03).
- No test may open the real browser: external URLs go through main's externalShell, which in e2e writes them to AYA_E2E_OPEN_EXTERNAL_LOG instead of opening them. Assert that log; never stub shell.openExternal from a spec (2026-10-21, test runs opened github.com tabs).
- Run e2e locally without `CI=1`. `CI` turns off `AYA_E2E_HEADLESS` (CI has xvfb), so on a Mac every test window appears on the user's screen (2026-10-21).
- Rebuild (`npm run build && npm run build:test-src`) in the checkout before an e2e run; the specs run the built `dist`, not the source.
- A headless test run must leave no icon in the macOS Dock or menu bar. Two layers: e2e launches a cached copy of Electron.app with `LSUIElement` set (`headlessElectronBinary` in `e2e/fixtures.ts`), because a stock Electron gets a Dock tile at process start and the Dock keeps the tile after exit; `main.ts` also takes the accessory policy under `AYA_E2E_HEADLESS=1`. `e2e/headless-dock.spec.ts` asserts both. A new launch path must go through `launchE2eElectron`/`spawnE2eElectron`. Check by counting Dock items before and after a run: `osascript -e 'tell application "System Events" to tell process "Dock" to return count of UI elements of list 1'`; `killall Dock` clears stale tiles (2026-11-09: 558 "Electron" tiles left by test runs, 22 more after the first fix).
- An e2e test that runs `bin/aya` with a pane's env (`AYA_TERMINAL_ID` plus `AYA_HOME`) while Aya is still starting must spawn it with `spawn(..., { detached: true })` (not `execFile`, which ignores it). Aya's startup sweep (`sweepLegacyAyaProcesses`, S2) SIGKILLs any such process whose process-group leader is gone, and the group leader is gone whenever the suite was started from a shell that has exited, e.g. a backgrounded run (2026-11-09: `Killed: 9` in `team-starting`, 12/12 from a detached shell, 0/48 from a live one).
