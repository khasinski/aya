Built to run many agents at once.

Every terminal is real and persistent. Aya keeps them organized across repositories, reads their rendered screens to spot blocked turns, and lets them coordinate without proxying your API keys.

Never hunt for the blocked agent.

The status rail lists every terminal that is waiting or failed across all your open projects, even ones you are not looking at. Waiting state is read off a headless VT mirror of the pane's real screen, so it clears the moment the agent repaints.

  • Click any row in the rail to jump straight to that pane.
  • Inspect decisions with aya pane state --explain or custom screen rules.
  • Report status from scripts inline via OSC 7501 or aya status.

Split like a real tiling terminal.

Splitting divides only the selected pane, so the rest of the layout keeps its size. Nest splits arbitrarily, choose between projects on top or on the left, and tear project tabs out into separate windows.

  • BSP splits with independent draggable dividers.
  • Start multiple Git worktrees from one prompt and group panes by checkout.
  • Keyboard navigation follows what you see on screen.

Let agents work as a team.

With aya pane read and aya pane send, one pane delegates work to another and collects the result. For structured workflows, define roles and message routes in .aya/teams/<name>.md and let Aya supervise the rounds.

  • Agents learn their role via aya team whoami and message teammates by role.
  • Holds delivery into aya team inbox when an approval prompt or draft is on screen.
  • Tracks real git commits and file edits to spot teams that are only talking.

Close the app. Update the app. They keep running.

Terminals live in a native PTY owner with headless VT checkpointing, not inside the window. Quit and relaunch, install an update, or reconnect from Aya Web, and every session resumes mid-conversation—with on-device Apple Intelligence labels under every tab and project.

  • Preserves up to 128 live panes across host restarts and app updates.
  • Session-precise resume for Claude Code, Codex, Grok, OpenCode, and more.
  • On-device summaries via Apple Intelligence or Ollama, plus full-text ⌘K search.

Terminal-native from every side.

The aya CLI opens projects from any shell, lets scripts report status, drives panes by name, and coordinates multi-agent teams. Enable “Tell the agent about aya” on a preset and agents discover the commands themselves via aya capabilities.

aya command-line interface
$ aya ~/Projects/aya
# opens this repository as a project (or focuses it)

$ aya pane read "reviewer"
# returns another pane's rendered screen as plain text

$ aya pane send "reviewer" "Review the diff and run npm test"
# types into that pane and presses Enter (--no-submit only types)

$ aya pane wait "reviewer"
# blocks until the pane settles back to waiting or idle

$ aya team open ux-fix lead=claude fixer=codex tester=this
$ aya team start ux-fix "Make the split divider keyboard-resizable"
# assigns panes to roles in .aya/teams/ux-fix.md and starts round 1

$ aya machines
# lists GPU, memory, and loaded Ollama models across your SSH hosts

Install Aya.

Download the latest release for macOS Apple Silicon or Linux x64. The macOS DMG and zip are Developer ID signed and Apple-notarized; Linux ships a FUSE3 AppImage and DEB package.

Download latest Changelog
build from source
git clone https://github.com/khasinski/aya.git
cd aya
npm install
npm run package
